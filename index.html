Het schema

Weken starten op maandag. Je kiest zelf je dagen, met een rustdag ertussen. Elke vierde week is lichter zodat je lijf kan bijkomen. Bij sommige runs staan snelle stukjes: die zijn optioneel, de hele run rustig lopen telt ook. Elke run heeft een ⏱ timer die piept als je moet wisselen. Op vakantie of een drukke week? Kies bij die week bij "Mijn week" voor Light (1 à 2 keer bewegen) of Rustig (2 runs). Punten: korte run 1, lange run 2, challenge 3.

De spelregels

KletstempoJe moet kunnen praten tijdens het lopen. Lukt dat niet, ga langzamer.
Run gemist?Gewoon door met de volgende. Niet inhalen met twee runs achter elkaar.
Drukke weekDoe in elk geval de lange run. Twee runs is prima, nul liever niet.
Pijn of spierpijn?Scherpe of terugkerende pijn: een paar dagen rust en bij twijfel naar een fysio.
Goede schoenenLaat je adviseren in een hardloopwinkel. De beste investering van dit plan.
De prijsWie op 15 mei de meeste punten heeft, kiest waar we na de finish gaan eten.
